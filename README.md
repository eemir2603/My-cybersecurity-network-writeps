# Section 1: Network Basics

## What is a network?

A computer network is a group of interconnected devices that can exchange data and share resources. These devices communicate through wired or wireless connections.

They follow communication rules called **network protocols**. Protocols define how data is formatted, transmitted, and received.

### Network vs. protocol

- **Network:** the connected devices and the links that allow them to communicate.
- **Protocol:** the agreed rules that devices follow when communicating.

### Examples of networked devices

- Personal computers and smartphones
- Servers
- Printers
- Routers and switches
- Smart-home devices
- Industrial control systems (ICS) and electronic control units (ECUs)

In vehicles, ECUs can exchange data over in-vehicle networks such as the Controller Area Network (CAN).
